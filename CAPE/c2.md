What is a Service Principal Name (SPN)? | A unique service instance identifier assigned to service accounts that run on domain computers under a domain user account context.
Why is the krbtgt SPN not exploitable for Kerberoasting? | While krbtgt always has an SPN set, it is a special account used by the Key Distribution Center and is not exploitable through standard Kerberoasting.
What is Kerberoasting? | A technique to retrieve krb5tgs hashes by requesting a TGS ticket for a target service account. The service account's password hash encrypts the TGS ticket, so the hash can be cracked offline to obtain the plaintext password.
Why should you only Kerberoast specified users instead of all users with SPNs? | To minimize noise and detection risk; Kerberoasting all users generates excessive traffic and alerts that defenders can detect.
What is ASREPRoasting? | An attack targeting domain users that do not require Kerberos Pre-Authentication. An AS-REP can be requested for such users, and the krb5asrep hash from the reply can be cracked offline to obtain the plaintext password.
What Windows feature must be set on a user account for ASREPRoasting to work? | The DoesNotRequirePreAuth flag must be set to True on the user account.
What does the setspn.exe utility do? | It is a built-in Windows utility that provides functionality to read, modify, and delete Service Principal Names (SPNs).
What is impersonation in Windows security? | The process of changing the current access token of the user you run as to another user's token, allowing access to resources that the other user can access.
What does the make-token command do in Sliver? | It creates a new Logon Session from specified credentials and impersonates the resulting token, defaulting to LOGON32_LOGON_NEW_CREDENTIALS logon type.
What is the default logon type used by make-token in Sliver? | LOGON32_LOGON_NEW_CREDENTIALS, which allows the current user to clone its token while specifying new credentials for outbound connections.
What is LOGON_INTERACTIVE logon type? | A type of logon mostly used by every user on the computer, be it using a console, RDP session, or else.
What is LOGON_NETWORK logon type? | A type of logon intended for high-performance servers that accept authenticators such as a password, NT hash, or Kerberos ticket.
What is LOGON_NEW_CREDENTIALS logon type? | A type of logon that allows the current user to clone its token while specifying a new set of credentials for outbound connections.
What Windows API call does Sliver's make-token use? | The LogonUserW syscall.
What is lateral movement? | The process where an attacker utilizes harvested credentials of other users, or hijacks processes running in their context, to access resources as those users on other machines across the domain.
What are the two prerequisites for PsExec to work? | The target host must have port 445 open, and the user must have local administrator privileges on the target host.
How does PsExec work? | It uploads a service binary to the target, creates and starts a new Windows service to execute the binary, and provides interactive access with SYSTEM privilege.
Why is Microsoft-signed PsExec.exe less likely to be flagged by AV? | Because Microsoft signs it. However, service binaries generated by C2 frameworks are easily flagged by AV.
What is a pivot listener in Sliver? | A listener started on a compromised host that allows other internal hosts to communicate through it back to the C2 server, creating a chain of communication when direct communication is not possible.
What two types of pivot listeners does Sliver support? | TCP pivot listeners and named-pipe listeners.

What is WMIC used for in lateral movement? | WMIC (Windows Management Instrumentation) enables remote code execution and lateral movement by creating processes on remote systems. It requires local administrator privilege.
Why might wmiexec.py get detected? | Because it writes the output of command execution to a file on the ADMIN$ share by default, which can be monitored.
What is DCOM and why is it useful for lateral movement? | Component Object Model (COM) is a platform-independent system for creating binary software components. DCOM enables remote code execution and lateral movement, and is harder to detect because DCOM has many methods with different IOCs.
What three DCOM objects can be used with dcomexec? | MMC20, ShellWindows, and ShellBrowserWindow.
What is unconstrained delegation in Kerberos? | A configuration where a computer or user is trusted for delegation to any service. When configured, the KDC includes the user's TGT in the TGS ticket, allowing the delegated server to cache and reuse the user's TGT to access any service on behalf of that user.
Why is unconstrained delegation dangerous if the server is compromised? | An attacker can extract all cached TGTs from memory and impersonate those users. If a high-privileged user's TGT (like a domain administrator's) is cached, the attacker can take over the whole domain and forest.
What is the double hop problem that unconstrained delegation resolves? | When a user authenticates to a front-end service that needs to access a back-end service on behalf of the user, the front-end service needs the user's TGT to request a new TGS for the back-end service.
What does SpoolSample exploit? | It coerces a computer to authenticate to another computer via the MS-RPRN RPC interface, which can be abused to capture TGTs on servers with unconstrained delegation.
How can a captured DC computer account TGT be used even though computer accounts don't have local admin privileges? | Since it's the domain controller's account, DCSync privilege can be used to get the domain administrator's hash and compromise the domain.
What is constrained delegation? | A more secure form of delegation where the server can only act on behalf of users to access specified services on specified computers, rather than any service.
What are the two sub-options for constrained delegation configuration? | "Use Kerberos only" and "Use any authentication protocol."
What is the alternate service name trick in constrained delegation? | Since the service name is not verified by S4U and is not encrypted in the ticket, an attacker can modify the target service name to access services not originally specified in the delegation configuration.
What is S4U2Self? | A Kerberos extension that allows a service to request a TGS ticket for a user to access itself, used as the first step in constrained delegation exploitation.
What is S4U2Proxy? | A Kerberos extension that allows a service to use a forwardable TGS ticket obtained via S4U2Self to request a TGS ticket for the user to access another service.
Why might a domain admin account be configured as "cannot be delegated"? | To prevent delegation attacks from impersonating that account, as a security measure to protect highly privileged accounts.
What tool can be used to dump credentials from lsass.exe memory? | nanodump, mimikatz, or pypykatz (for offline analysis of memory dumps).
What is PPL (Protected Process Light)? | A Windows security feature that protects certain processes (like lsass.exe) from being accessed even by SYSTEM-level processes, as PPL has a higher integrity level than SYSTEM.
How can PPL be bypassed? | By using vulnerable signed drivers (like RTCore64.sys or ProcExp152.sys) to execute arbitrary code and remove PPL protection, using tools like EDRSandblast, PPLControl, or RToolZ.
What is a DACL in Active Directory? | A Discretionary Access Control List - a list of access control entries (ACEs) that specifies which users or groups are allowed or denied access to specific resources like computers, SMB shares, or user accounts.
What are four ways ACLs can be exploited in Active Directory? | Using privileged accounts to modify DACLs, lack of segregation of duties, unrestricted access to objects, and misconfigured permissions.
What naming convention does the BloodHound ingestor use by default that can trigger detection? | The default naming convention is BloodHound.zip for the output file, and files ending in _computers.json, _containers.json, _domains.json, etc.
What is ForceChangePassword permission? | A DACL permission that allows a user to change another user's password without knowing the original password.
What is GenericWrite permission in Active Directory? | A permission that allows a user to modify attributes of another object, such as setting an SPN or disabling Kerberos pre-authentication for a target user.
How can GenericWrite permission be abused for Kerberoasting? | By setting a fake SPN on the target user account, then requesting a TGS ticket for that SPN and cracking the hash offline.
What is DCSync? | A feature that allows authorized users with specific replication permissions to access credentials for any user within the domain by simulating domain controller replication.
What three permissions are needed for DCSync? | Replicating Directory Changes, Replicating Directory Changes All, and Replicating Directory Changes In Filtered Set.
Which groups have DCSync permission by default? | Domain Admins, Enterprise Admins, Administrators, and Domain Controllers.
What is AdminSDHolder? | A unique security principal in Active Directory that protects certain built-in sensitive principals (Domain Admins, Enterprise Admins, Schema Admins, etc.) from unauthorized modification.
What is the Security Descriptor Propagator (SDProp)? | A process that compares the ACL of protected principals with the ACL defined in AdminSDHolder, reverting unauthorized changes typically within one hour.
How can AdminSDHolder be abused for persistence? | By modifying the AdminSDHolder object itself to grant a controlled user Full Control, which then propagates to all protected groups.
What is a Skeleton Key attack? | A technique that patches the lsass.exe process on the domain controller to bypass authentication, allowing any user to authenticate with a specific password while real passwords still work.
Is the Skeleton Key technique persistent after reboot? | No, the skeleton key technique is not persistent after a reboot.
What is a Malicious SSP (Security Support Provider)? | A backdoor that injects a custom SSP into lsass.exe, causing plaintext passwords to be logged to a file (C:\Windows\System32\mimilsa.log) when users log on.
What are Security Support Providers (SSPs)? | Part of the Windows operating system that offer ways for an application to obtain an authenticated connection. Examples include Kerberos, NTLM, Wdigest, and msv.
What is a Golden Ticket? | A forged TGT signed and encrypted with the krbtgt account's hash that can impersonate any user with any privilege, providing access to any service in the domain.
What are two common detection techniques for Golden Tickets? | TGS-REQs that have no corresponding AS-REQ, and TGTs with a 10-year lifetime (the default created by Mimikatz).
What is a Silver Ticket? | A forged service ticket (TGS) that can impersonate any user to access a specific service on a specific machine. It requires the computer account's credentials (NTLM/AES256).
How long is a Silver Ticket useful for persistence by default? | 30 days, because computer account passwords change every 30 days by default.
What services can be targeted with Silver Tickets for different access types? | PsExec needs CIFS; WMI needs HOST and RPCSS; WinRM needs HOST and HTTP; Scheduled Tasks need HOST.
What is a Diamond Ticket? | A TGT made by modifying a legitimate TGT issued by the domain controller - decrypting it with krbtgt's credential, changing specific fields, and re-encrypting it, making it harder to detect than a golden ticket.
What is a domain trust? | A trust relationship between domains that enables users in one domain to access resources in another domain.
What is the difference between one-way and two-way trust? | Two-way trust allows users in either domain to access resources in both domains. One-way trust only allows users in one domain to access resources in the other, divided into inbound and outbound trust.
What is the difference between Domain Admins and Enterprise Admins? | Domain Admins have the highest privilege within their domain only, while Enterprise Admins in the root domain have the highest privilege over the entire forest.
What is a foreign security principal? | A security principal from a trusted domain that is granted access to resources in the target domain, requiring a domain trust relationship.
What is SID history? | An attribute that supports security principals in maintaining access to resources in a previous domain after migration by storing their previous SIDs.
What is a trust key in domain trusts? | A shared secret stored in a special computer account created when domain trust is established. The account name matches the other domain's NetBIOS name, and it's used to sign inter-realm TGTs.
How can krbtgt be abused to move from a child domain to a parent domain? | By creating a diamond or golden ticket with the child domain's krbtgt hash and specifying the Enterprise Admins SID from the parent domain as an extra SID.
How can the trust key be abused for forest compromise? | By forging an inter-realm TGT using the trust key (NTLM hash of the trust account), then injecting it into memory to access resources in the parent domain with Enterprise Admin privileges.
What is a C2 (Command and Control) server? | Software tasked to execute commands or binaries on remote computers, providing centralized management of access to machines in a network.
