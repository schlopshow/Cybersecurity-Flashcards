What is Active Directory Certificate Services (ADCS)?|A Windows server role that enables organizations to establish and manage their own Public Key Infrastructure (PKI), integrating with Active Directory Domain Services for certificate management and authentication
What is Public Key Infrastructure (PKI)?|A system that uses digital certificates and public key cryptography to provide secure communication over unsecured networks, enabling digital signatures, encryption, and authentication
What is a digital certificate?|An electronic document that binds a public key to a person, organization, device, or service, issued and signed by a trusted Certificate Authority (CA)
What are the three benefits of PKI?|Confidentiality (encrypt stored/transmitted data), Integrity (digital signature identifies if data is modified), Authenticity (message digest signed with sender's private key proves origin via non-repudiation)
What advantages does ADCS have over standard PKI?|Tight integration with AD DS, built-in certificate revocation support (CRL and OCSP), support for custom certificate templates, and scalability/redundancy with multiple CAs
What is a Certificate Authority (CA)?|A component that issues certificates to users, computers, and services while overseeing certificate validity management
What is the difference between a Standalone CA and an Enterprise CA?|Standalone CAs operate autonomously without Active Directory allowing manual or web-based requests; Enterprise CAs rely on Active Directory and automate processes using Group Policy or Certificate Enrollment Web Services
What are Certificate Templates in ADCS?|Predefined configurations stored as AD objects that dictate properties and usage of certificates, including purpose, key size, validity period, issuance policies, and enrollment permissions
What is a Certificate Signing Request (CSR)?|A request submitted by users or devices to a CA containing the public key and identifying information to obtain a certificate
What is a Certificate Revocation List (CRL)?|A digitally signed inventory issued by a CA cataloging revoked certificates, allowing entities to verify the revoked status of specific certificates
What are Extended Key Usages (EKUs)?|Certificate extensions that define authorized uses for a certificate, such as code signing, email encryption, client authentication, or smart card logon
What are the EKU OIDs that enable authentication to Active Directory?|Client Authentication (1.3.6.1.5.5.7.3.2), PKINIT Client Authentication (1.3.6.1.5.2.3.4), Smart Card Logon (1.3.6.1.4.1.311.20.2.2), Any Purpose (2.5.29.37.0), and SubCA (no EKUs)
What is the OID for Client Authentication?|1.3.6.1.5.5.7.3.2
What is the OID for Smart Card Logon?|1.3.6.1.4.1.311.20.2.2
What is the OID for PKINIT Client Authentication?|1.3.6.1.5.2.3.4
What is the OID for Any Purpose?|2.5.29.37.0
What is the OID for Certificate Request Agent (Enrollment Agent)?|1.3.6.1.4.1.311.20.2.1
Where are ADCS-related containers stored in Active Directory?|Under CN=Public Key Services, CN=Services, CN=Configuration, DC={forest root domain}
What are the four locations where ADCS stores trusted root CA certificates?|Certification Authorities container, Enrollment Services container, NTAuthCertificates AD object, and AIA (Authority Information Access) container
What does the Certification Authorities container hold?|Top-tier root CA certificates forming the foundation of trust, incorporated into the Trusted Root Certification Authorities store on Windows machines
What does the Enrollment Services container hold?|AD objects for each Enterprise CA with attributes like certificate data, DNS hostname, and certificate templates
What does the NTAuthCertificates AD object define?|CA certificates pivotal for authenticating to AD; client certificates must be signed by one of the CAs listed within NTAuthCertificates
What does the AIA container hold?|AD objects representing intermediate and cross CAs that aid in validating certificate chains
What are the key fields in an X.509 certificate?|Subject, Public Key, NotBefore/NotAfter dates, Serial Number, Issuer, SubjectAlternativeName, Basic Constraints, Extended Key Usages, and Signature Algorithm/Signature
What are the two issuance requirements that govern certificate enrollment beyond template and CA access controls?|Manager approval (CA certificate manager approval) and authorized signatures requirement (number of required signatures in the CSR)
What does the CT_FLAG_PEND_ALL_REQUESTS flag do?|Places all certificate requests based on the template into a pending state, requiring a certificate manager's approval before the certificate can be issued
What are the steps of the certificate enrollment process?|1) Find Enterprise CA, 2) Generate key pair and create CSR, 3) Sign CSR with private key and send to CA, 4) CA checks authorization, 5) CA generates and signs certificate if allowed, 6) Client receives and stores certificate
What is the built-in group that indicates ADCS is installed in a domain?|Cert Publishers - this group typically authorizes Certificate Authorities to publish certificates to the directory
What is Certify?|A C# tool developed by SpecterOps designed to enumerate and exploit misconfigurations within ADCS from Windows
What is Certipy?|A Python tool created by Oliver Lyak for enumerating and exploiting ADCS misconfigurations from Linux, featuring BloodHound support
What are the categories of ADCS attacks?|Abusing Certificate Templates (ESC1-3, ESC9-10), Abusing CA Configuration (ESC6), Abusing Access Control (ESC4, ESC5, ESC7), NTLM Relay (ESC8, ESC11), and Miscellaneous (Certifried, PKINIT not supported)
What is ESC1?|A domain escalation scenario where a certificate template allows specifying an alternate Subject Alternative Name (SAN) in the CSR, enabling authentication as any user
What are the abuse requirements for ESC1?|Enterprise CA grants enrollment to low-privileged users, manager approval is off, no authorized signatures required, permissive security descriptor, template defines authentication EKUs, and template allows requesters to specify a SAN
What does the ENROLLEE_SUPPLIES_SUBJECT flag indicate?|The certificate template allows the requester to specify a Subject Alternative Name in the Certificate Signing Request
What is ESC2?|A variation of ESC1 where a certificate template specifies Any Purpose EKU or no EKU at all, allowing the certificate to be used for any purpose including client authentication
How does ESC2 differ from ESC1?|ESC2 focuses on templates with Any Purpose EKU or no EKU specified; if the template also allows specifying a SAN, it can be exploited the same way as ESC1
What is a subordinate CA certificate in the context of ESC2?|A certificate with no EKUs that can be used to sign new certificates with arbitrary EKUs and values, though it won't function for domain authentication unless trusted by NTAuthCertificates
What is ESC3?|An escalation scenario that abuses Misconfigured Enrollment Agent Templates with the Certificate Request Agent EKU, allowing a principal to request certificates on behalf of other users
What are the two conditions required for ESC3?|Condition 1: A template granting enrollment agent certificates to low-privileged users with Certificate Request Agent EKU. Condition 2: Another template permitting use of the enrollment agent certificate to request certificates on behalf of others with domain authentication EKU
How does ESC3 work in practice?|First obtain a certificate from the template with Certificate Request Agent EKU, then use that certificate to co-sign a CSR on behalf of another user using a template that allows client authentication
What is ESC4?|A domain escalation that exploits misconfigured access control on certificate templates, where unprivileged users have editing permissions that allow them to modify template settings to make it vulnerable to ESC1
What access control entries make a template vulnerable to ESC4?|ACEs that grant Full Control, WriteOwner, WriteDacl, or WriteProperty to unintended or unprivileged AD principals over the certificate template
What modifications are needed to make a template vulnerable via ESC4?|Grant enrollment rights, disable PEND_ALL_REQUESTS flag, set mspki-ra-signature to 0, enable ENROLLEE_SUPPLIES_SUBJECT flag, and set certificate application policy to an authentication purpose OID
What is the mspki-certificate-name-flag attribute?|An attribute that controls whether the certificate template allows requesters to specify subject information; enabling ENROLLEE_SUPPLIES_SUBJECT (value 1) allows specifying a SAN
What is the mspki-enrollment-flag attribute?|An attribute that controls enrollment behavior; the PEND_ALL_REQUESTS flag (0x00000002) requires manager approval for all requests
What is the mspki-ra-signature attribute?|An attribute that specifies the number of authorized signatures required in a CSR; setting it to 0 disables the authorized signature requirement
Why is Certify's ESC4 detection different from Certipy's?|Certify will not mark a template with elevated privileges as vulnerable for ESC4; the user must manually identify it by examining the Object Control Permissions section
What is ESC5?|A domain escalation that abuses access controls over Active Directory objects indirectly connected to ADCS, such as the CA server's computer object or objects within the Public Key Services container
What objects can be targeted in ESC5?|The CA server's AD computer object, the CA server's RPC/DCOM server, and any descendant AD object or container in CN=Public Key Services,CN=Services,CN=Configuration (Certificate Templates container, Certification Authorities container, NTAuthCertificates object, Enrollment Services Container)
How does ESC5 differ from ESC4 and ESC7?|ESC5 targets objects indirectly connected to ADCS rather than the templates or CA directly, such as gaining local admin on the ADCS server to then abuse ESC4 or ESC7
What is ESC6?|A CA-level misconfiguration where the EDITF_ATTRIBUTESUBJECTALTNAME2 flag is set, allowing any certificate request to include user-defined Subject Alternative Names regardless of template settings
What does the EDITF_ATTRIBUTESUBJECTALTNAME2 flag do?|When set on the CA, it allows any certificate request (including those built from Active Directory) to have user-defined values in the subject alternative name, making all authentication-capable templates exploitable like ESC1
Was ESC6 patched?|Yes, it was patched as part of the May 2022 Security Updates from Microsoft related to CVE-2022-26923, but some companies may not have applied the updates
How does ESC6 differ from ESC1?|In ESC6, alternative names are included in a CSR as a certificate attribute; in ESC1, the SAN is stored as a certificate extension. ESC6 affects the entire CA, not just individual templates
What is ESC7?|A domain escalation that exploits ManageCA and/or ManageCertificates rights on the Certificate Authority to manipulate CA configuration or approve pending certificate requests
What are the two primary rights exploited in ESC7?|ManageCA (CA administrator role) allows modifying CA configuration including the EDITF_ATTRIBUTESUBJECTALTNAME2 flag; ManageCertificates (Certificate Manager/CA officer) allows approving pending certificate requests
How can ManageCA rights be abused in ESC7?|By enabling EDITF_ATTRIBUTESUBJECTALTNAME2 to perform ESC6, or by granting ManageCertificates rights to an account and then approving failed certificate requests using the SubCA template
What is the SubCA template?|A built-in template that is enabled by default, vulnerable to ESC1 but only permits Domain Admins and Enterprise Admins to enroll; can be exploited via ESC7 by issuing denied requests
How does ESC7 with ManageCertificates work?|Find a template matching ESC1 requirements except with manager approval enabled, request a certificate with an alternative SAN (request will be pending), then use ManageCertificates rights to approve the pending request
What tool is PSPKI?|A PowerShell module that provides cmdlets for managing Certificate Authorities, including Get-CertificationAuthority and Get-CertificationAuthorityAcl for enumerating CA permissions
What is the EditFlags value that includes EDITF_ATTRIBUTESUBJECTALTNAME2?|1376590 (decimal) or 0x15014e (hex); without the flag it is 1114446 (decimal) or 0x11014e (hex)
What is ESC8?|NTLM Relay to AD CS HTTP Endpoints - exploiting web enrollment endpoints to relay coerced NTLM authentication and request certificates on behalf of the authenticated machine/user
What are the conditions for ESC8 abuse?|A vulnerable web enrollment endpoint (HTTP-based) and at least one certificate template that allows domain computer enrollment and client authentication (like the default Machine/Computer template)
Why can HTTP NTLM authentication be relayed?|The HTTP protocol does not verify the NTLM signature during authentication, making it possible to relay coerced authentication to the PKI server's HTTP endpoint
What is authentication coercion?|An attack that forces a client to authenticate against an attacker-controlled machine, typically by exploiting insecure code in protocols that trigger automatic authentication when accessing UNC paths
What tools can be used for authentication coercion?|PetitPotam, PrinterBug, and Coercer - they use different methods to force machines to authenticate
What template should be used when relaying authentication from a domain controller in ESC8?|The DomainController template; for non-DC machines, the Machine template should be used
What are the two exploitation options after obtaining a machine certificate via ESC8?|1) DCSync attack (if the certificate is for a domain controller), or 2) Silver Ticket attack (works for any machine)
What is needed to forge a Silver Ticket?|The target machine's NT hash, the Domain SID, and a specific SPN to abuse
What is ESC11?|NTLM Relay to AD CS ICPR (RPC) Endpoints - similar to ESC8 but uses RPC/ICPR enrollment endpoints instead of HTTP
What flag determines if ESC11 is exploitable?|The IF_ENFORCEENCRYPTICERTREQUEST flag - if not set, unencrypted sessions can be used for certificate enrollment via RPC
How does ESC11 differ from ESC8?|ESC11 relays coerced SMB NTLM authentication over RPC/ICPR instead of HTTP, targeting the MS-ICPR RPC interface rather than web enrollment endpoints
What is Certifried (CVE-2022-26923)?|A vulnerability in AD Domain Services where attackers exploit the lack of restrictions on dNSHostName values to obtain certificates that allow impersonating domain controllers
How does Certifried work?|1) Create or compromise a computer account, 2) Clear SPNs to avoid constraint violations, 3) Set dNSHostName to match a DC's hostname, 4) Request a certificate using the Machine template, 5) The certificate maps to the DC based on the dNSHostName
What was the pre-patch certificate mapping based on for the Machine template?|The dNSHostName property value - changing this to match another computer's hostname would result in a certificate mapped to that computer
How do you check if Certifried is patched?|Request a certificate from a standard template; if the output indicates "Certificate has no object SID," no strong mapping is performed and the CA may be vulnerable
What is PKINIT?|Public Key Cryptography for Initial Authentication in Kerberos - an extension that enables public key cryptography for initial authentication, using X.509 certificates instead of symmetric keys
What is Schannel authentication?|Windows' security support provider for TLS/SSL connections that handles client authentication by verifying connecting users' identity using PKI certificates during the TLS handshake
What error indicates PKINIT is not supported?|KDC_ERR_PADATA_TYPE_NOSUPP - meaning the KDC has no support for PADATA type (pre-authentication data), often because domain controllers lack certificates with the Smart Card Logon EKU
What is PassTheCert?|A tool by Yannick Méheut (Python and C#) that allows authenticating via LDAPS using a certificate when PKINIT is not supported, using Schannel authentication
What four attacks does PassTheCert implement?|1) Granting DCSync rights to a user, 2) Modifying msDS-AllowedToActOnBehalfOfOtherIdentity for RBCD attack, 3) Adding a computer to the domain, 4) Resetting an account password
What is certificate mapping in ADCS?|The process of associating issued certificates with their respective subjects to identify which user or computer a certificate belongs to
What is the szOID_NTDS_CA_SECURITY_EXT certificate extension?|A security extension added after CVE-2022-26923 that contains the objectSid of the certificate requester for strong certificate mapping
What is the StrongCertificateBindingEnforcement registry key?|A key used for Kerberos implicit certificate mapping with values: 0 (disabled/no strong mapping), 1 (default compatibility mode), 2 (full enforcement mode)
What does StrongCertificateBindingEnforcement value 0 mean?|No strong certificate mapping is performed; the szOID_NTDS_CA_SECURITY_EXT extension is not checked, behaving as before the patch (Disabled mode)
What does StrongCertificateBindingEnforcement value 1 mean?|Default compatibility mode - KDC checks for explicit mapping first, then security extension; if extension is absent, authentication may be allowed if the user account predates the certificate
What does StrongCertificateBindingEnforcement value 2 mean?|Full enforcement mode - KDC checks explicit mapping, then security extension; if the extension is absent, authentication is refused
What is the CertificateMappingMethods registry key?|A key used for Schannel implicit certificate mapping with combinable values: 0x0001 (Subject/issuer), 0x0002 (Issuer), 0x0004 (SAN implicit), 0x0008 (S4USelf implicit Kerberos), 0x0010 (S4USelf explicit Kerberos)
What is the default value of CertificateMappingMethods?|0x18 (combination of 0x8 S4USelf implicit Kerberos and 0x10 S4USelf explicit Kerberos)
What is the difference between explicit and implicit certificate mapping?|Explicit mapping uses the altSecurityIdentities attribute of the account; implicit mapping uses information in the certificate's SAN to map with DNS or UPN fields
What is ESC9?|An escalation that exploits the CT_FLAG_NO_SECURITY_EXTENSION flag in a certificate template, which prevents embedding the szOID_NTDS_CA_SECURITY_EXT security extension, effectively bypassing strong certificate mapping
What does the CT_FLAG_NO_SECURITY_EXTENSION flag do?|It prevents the embedding of the szOID_NTDS_CA_SECURITY_EXT security extension in issued certificates, causing mapping to behave as if StrongCertificateBindingEnforcement is 0 regardless of actual setting
What are the requirements for ESC9?|StrongCertificateBindingEnforcement not set to 2 or CertificateMappingMethods contains UPN flag (0x4), template has CT_FLAG_NO_SECURITY_EXTENSION flag, template specifies client authentication, and attacker has GenericWrite over a user account
How does the ESC9 attack work?|1) Have GenericWrite over account A, 2) Change account A's UPN to match target account B's UPN, 3) Request certificate as account A using vulnerable template, 4) Certificate maps to account B due to UPN match without SID verification, 5) Revert A's UPN, 6) Authenticate as B
What is the NoSecurityExtension value in certipy output?|It indicates the CT_FLAG_NO_SECURITY_EXTENSION flag is set in the msPKI-Enrollment-Flag attribute, making the template potentially vulnerable to ESC9
What is ESC10?|An escalation similar to ESC9 but focusing on misconfigurations in registry keys (StrongCertificateBindingEnforcement or CertificateMappingMethods) rather than template configurations
What are the two cases of ESC10?|Case 1: StrongCertificateBindingEnforcement set to 0 (exploited via Kerberos authentication). Case 2: CertificateMappingMethods set to 0x4/contains UPN flag (exploited via Schannel authentication)
What are the requirements for ESC10 Case 1?|StrongCertificateBindingEnforcement set to 0, at least one template with client authentication enabled, and GenericWrite rights over a user account
How does ESC10 Case 1 differ from ESC9?|ESC10 Case 1 exploits the registry key being set to 0 rather than a template flag, and can use any template allowing client authentication (like the built-in User template)
What are the requirements for ESC10 Case 2?|CertificateMappingMethods set to 0x4, at least one template with client authentication, and GenericWrite rights over a user account to compromise an account without an existing UPN (like machine accounts or built-in Administrator)
How does ESC10 Case 2 exploitation differ from Case 1?|Case 2 requires Schannel authentication (not Kerberos PKINIT), so the certificate is used with LDAPS; typically involves creating a computer account and setting up RBCD delegation
What is Shadow Credentials in the context of ADCS attacks?|A technique to add key credentials to a user account to obtain authentication as that user without changing their password, useful when you have GenericWrite over the account
What tool is used for Shadow Credentials in ADCS attacks?|Certipy with the "shadow auto" option, which generates a certificate, adds a Key Credential, authenticates, retrieves the NT hash, and restores the original Key Credentials
What is the difference between ManageCA and ManageCertificates rights?|ManageCA allows configuring the CA's settings and adding officers; ManageCertificates allows approving or denying pending certificate requests
How can ManageCA rights be used to grant ManageCertificates?|Use certipy ca with the -add-officer flag to assign ManageCertificates rights to any account
What is the PEND_ALL_REQUESTS flag value?|0x00000002 in the mspki-enrollment-flag attribute, which places all certificate requests into a pending state requiring manager approval
What is the ENROLLEE_SUPPLIES_SUBJECT flag value?|0x00000001 in the mspki-certificate-name-flag attribute, which allows requesters to specify a SAN in the CSR
What is Rubeus used for in ADCS attacks on Windows?|Requesting TGTs using certificates (PKINIT), performing Pass-the-Ticket attacks, creating sacrificial logon sessions, and retrieving NT hashes from certificates
What is the createnetonly option in Rubeus?|Creates a sacrificial logon session with a new process, allowing you to inject a TGT into that session without affecting the current session
What does the /getcredentials flag do in Rubeus asktgt?|Retrieves the NT hash of the account using U2U (User-to-User) authentication based on the certificate
What is the Certipy relay command used for?|Listening for NTLM authentication and relaying it to ADCS endpoints (HTTP for ESC8, RPC for ESC11) to request certificates on behalf of the authenticated account
What is the difference between the Machine and DomainController templates?|Machine is used for standard domain computer enrollment; DomainController is specifically for domain controllers and should be used when attacking DCs
What is the -save-old option in Certipy template command?|Saves the old template configuration to a JSON file so the template can be restored to its original state after the attack
What is the -on-behalf-of option in Certipy?|Used in ESC3 attacks to request a certificate on behalf of another user using an enrollment agent certificate
What is the -ldap-shell option in Certipy auth?|Authenticates via Schannel (LDAPS) instead of PKINIT and opens an LDAP shell for performing attacks like creating computer accounts or setting RBCD
What is the ly4k fork of BloodHound?|A forked version of BloodHound created by Oliver Lyak (Certipy developer) that includes ADCS nodes and edges for creating attack paths using certificate-related vulnerabilities
What data does Certipy output by default?|Text output (.txt), JSON output (.json), and BloodHound data (.zip) containing templates and Certificate Authorities information
How do you combine BloodHound and Certipy data for ADCS attack paths?|Import both the BloodHound-Python collected data and the Certipy BloodHound data into the ly4k forked version of BloodHound
What PKI section queries are available in the ly4k BloodHound fork?|Queries like "Shortest Paths to Misconfigured Certificate Template from Owned Principals (ESC1)" for identifying ADCS attack paths
What is the -bloodhound parameter in Certipy?|Outputs only BloodHound-compatible data instead of the default text, JSON, and BloodHound combined output
What is the Coercer tool?|A tool that performs authentication coercion attacks by forcing remote machines to authenticate to an attacker-controlled machine using various MS-RPC methods
What is PetitPotam?|A tool that elicits machine account authentication via MS-EFSRPC functions, used for authentication coercion in relay attacks
What is the purpose of RBCD (Resource-Based Constrained Delegation) in ADCS attacks?|When direct PKINIT authentication isn't possible, RBCD allows creating a computer account with delegation rights over a target, enabling impersonation of any user on that target
What is the msDS-AllowedToActOnBehalfOfOtherIdentity attribute?|An AD attribute on computer objects that defines which accounts can delegate (act on behalf of other identities) to that computer, used in RBCD attacks
What is the DCSync attack in the context of ADCS?|Using obtained domain controller credentials (hash or TGT) to replicate domain credentials from the DC using the DRSUAPI method to dump NTDS.DIT secrets
What is the KRB_AP_ERR_SKEW error?|A Kerberos error indicating the clock skew between the client and the KDC is too great; resolved by synchronizing time using ntpdate
What happens when you change a computer account's dNSHostName in Active Directory?|Normally, the DC updates SPNs to reflect the new hostname, raising a constraint violation if those SPNs exist for another account; clearing SPNs first bypasses this check (Certifried exploit)
What is the default number of machine accounts a user can create in Active Directory?|10 machine accounts (ms-DS-MachineAccountQuota default value)
What is the difference between how Certify and Certipy handle credentials?|Certify takes credentials from the current running session context; Certipy allows specifying credentials via command-line parameters
What does the "Certificate has no object SID" message mean in Certipy output?|No objectSID is embedded in the certificate via the szOID_NTDS_CA_SECURITY_EXT extension, meaning no strong mapping will be performed and only UPN/DNS will be used for mapping
What is the IF_ENFORCEENCRYPTICERTREQUEST flag?|A flag on the MS-ICPR RPC interface that determines whether encryption is enforced for certificate enrollment requests; if not set, ESC11 is possible
What is the web enrollment URL for ADCS?|Typically accessible at http://<servername>/certsrv/certfnsh.asp
What is PowerZure in relation to ADCS?|Not directly related to ADCS - it's a PowerShell framework for Azure assessment, but PassTheCert and PowerView are used for ADCS attacks on Windows
What is dacledit.py?|An Impacket tool (from ShutdownRepo fork) used to enumerate and modify DACLs on AD objects, useful for verifying GenericWrite/GenericAll rights needed for ESC9/ESC10
What is the significance of the User template in ADCS attacks?|It's a built-in template that allows Client Authentication and is available to Domain Users by default, making it useful for ESC3 (on-behalf-of requests), ESC6, ESC9, and ESC10 attacks
What is the significance of the SubCA template in ADCS attacks?|A built-in template enabled by default that is vulnerable to ESC1 but only allows Domain Admins/Enterprise Admins to enroll; useful in ESC7 attacks where denied requests can be manually approved
What does the -configuration option do in Certipy template command?|Restores a certificate template to a previously saved configuration (from -save-old), reverting attack modifications
What is the certificate enrollment process for ESC7 with SubCA?|1) Request certificate with SAN using SubCA (request denied due to enrollment rights), 2) Save the private key, 3) Use ManageCertificates rights to issue the denied request, 4) Retrieve the issued certificate using the saved key
What is PSPKI's Get-PendingRequest used for?|Enumerating all pending certificate requests on a CA, showing request IDs, requester names, and template information for approval/denial
What is PSPKI's Approve-CertificateRequest used for?|Approving pending certificate requests when you have ManageCertificates rights, enabling ESC7 exploitation from Windows
What is the Invoke-TheHash tool?|A PowerShell tool that allows performing Pass-the-Hash attacks, useful for executing commands with an NT hash obtained from ADCS attacks
What happens to the ESC6 vulnerability after May 2022 updates?|The EDITF_ATTRIBUTESUBJECTALTNAME2 flag misconfiguration was patched; the SAN specification through CSR attributes no longer works for domain authentication on updated systems
What is the CT_FLAG_INCLUDE_SYMMETRIC_ALGORITHMS flag value?|0x00000001 in the mspki-enrollment-flag attribute
What is the CT_FLAG_PUBLISH_TO_DS flag value?|0x00000008 in the mspki-enrollment-flag attribute
How do you combine CT_FLAG_INCLUDE_SYMMETRIC_ALGORITHMS and CT_FLAG_PUBLISH_TO_DS?|Set mspki-enrollment-flag to 9 (0x00000001 + 0x00000008 = 0x00000009)

What does the -target-ip option do in Certipy?|Specifies the ADCS server IP when it differs from the domain controller, necessary when the CA is on a separate server
What is the significance of the pkiextendedkeyusage attribute?|Defines the Extended Key Usages allowed for certificates issued from a template; determines what the certificate can be used for (authentication, signing, encryption, etc.)
