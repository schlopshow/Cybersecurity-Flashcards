What two main categories of detection mechanisms does Microsoft Defender Antivirus use?|Static Analysis (detecting malware on-disk before execution) and Dynamic Analysis (detecting active malware in process memory)
What is static analysis in the context of Microsoft Defender Antivirus?|Detection of malware on disk through signature scans, checking file hashes, byte patterns, and strings against a database of known malicious values
What is dynamic analysis in the context of Microsoft Defender Antivirus?|Detection of active malware in process memory, triggered by events such as new process creation or suspicious behavior
What are two examples of events that trigger Microsoft Defender Antivirus to scan files or processes?|File creation/modification (catching malicious files before execution) and suspicious behavior (e.g., Microsoft Word spawning PowerShell)
What is ThreatCheck used for?|It splits a file into chunks and makes Microsoft Defender Antivirus scan them to identify which specific bytes trigger a detection
Why is simple XOR encryption of shellcode insufficient to bypass Microsoft Defender Antivirus?|Microsoft Defender Antivirus can detect XOR-encrypted shellcode patterns, so more sophisticated encryption like AES is needed
Why does AES encryption of shellcode succeed in bypassing static analysis where XOR fails?|AES produces output that appears more random and doesn't match known signature patterns, unlike simple XOR which can still be recognized
What happens after bypassing static analysis with AES-encrypted shellcode when a shell command is executed?|The process gets detected by dynamic/behavioral analysis because the unencrypted shellcode resides in memory and triggers a memory scan
What are three options for evading dynamic/behavioral analysis?|Modifying the payload source code, changing to a less well-known payload, or writing custom tools from scratch
Why is changing from Meterpreter to a less known payload effective against behavioral analysis?|Microsoft Defender Antivirus likely does not have signatures for lesser-known shellcode, so even if a memory scan is triggered, nothing suspicious is detected
Why is writing custom tools the most effective method for evading antivirus detection?|Custom tools won't match any known malicious signatures in the antivirus database, so neither static nor behavioral analysis can detect them
What is process injection?|An evasion technique that entails running malicious code within the address space of another process
What are four types of process injection?|Dynamic-link Library Injection, Portable Executable Injection, Process Hollowing, and Thread Execution Hijacking
What is Portable Executable (PE) Injection?|A technique where attackers copy their code into the address space of a target process and execute it using functions like VirtualAllocEx, WriteProcessMemory, and CreateRemoteThread
What does VirtualAllocEx do in the context of PE injection?|Allocates space in the memory of the target process for shellcode
What does WriteProcessMemory do in the context of PE injection?|Writes shellcode into the allocated space in the target process's memory
What does CreateRemoteThread do in the context of PE injection?|Executes the shellcode in the target process by creating a new thread
Why is memory initially allocated as Read/Write and then changed to Read/Execute in PE injection?|Some antivirus solutions find it suspicious when Read/Write/Execute memory is allocated, so separating the steps is a simple workaround
What is Process Hollowing?|A technique where an attacker spawns a target process in a suspended state, replaces the entrypoint in memory with their own code, and then resumes the process
What is Thread Execution Hijacking?|A technique where an attacker suspends a thread in a target process, replaces the code with malicious code, and then resumes the thread
What is DLL Injection?|A technique where an attacker writes the path of a malicious DLL into the address space of a target process and then calls LoadLibrary
What is the Antimalware Scan Interface (AMSI)?|A standardized interface that Windows applications use to interact with antimalware software, allowing them to scan input for malicious content using functions like AmsiScanBuffer and AmsiScanString
How does AMSI relate to PowerShell?|AMSI acts as a way for PowerShell to run signature scans with Microsoft Defender Antivirus against commands before running them
What does bypassing AMSI mean?|Preventing PowerShell from using the AmsiScanBuffer and AmsiScanString functions so that commands are not scanned before execution
What is the amsiInitFailed bypass technique?|Setting the amsiInitFailed variable to true in System.Management.Automation.AmsiUtils, which causes the ScanContent method to always return AMSI_RESULT_NOT_DETECTED
How does the amsiScanBuffer patching bypass work?|By overwriting the beginning of the AmsiScanBuffer function with shellcode that always returns an error code (E_FAIL, 0x80004005), causing AMSI to think scanning failed
How does the AMSI bypass by forcing an error work?|By modifying amsiContext so that AmsiOpenSession fails (returns E_INVALIDARG, 0x80070057), which causes amsiInitFailed to be set to true, bypassing AMSI
What is string manipulation in the context of AMSI bypasses?|Techniques like splitting strings or base64-encoding them to avoid triggering AMSI detections on known bypass-related strings like "amsiUtils"
What is the difference between the amsiInitFailed bypass and the amsiScanBuffer patching bypass in terms of scope?|The amsiInitFailed bypass only disables AMSI for the PowerShell session, while the amsiScanBuffer patching bypass patches amsi.dll itself, also affecting .NET assembly loading
Why does reflectively loading .NET assemblies require patching amsi.dll rather than just setting amsiInitFailed?|Because setting amsiInitFailed only disables AMSI for the PowerShell session, but System.Reflection.Assembly.Load() triggers AMSI through amsi.dll, which remains unpatched
What are two options for modifying open-source software to evade antivirus detection?|Manually breaking signatures by iteratively modifying flagged bytes, or reflectively loading assemblies in PowerShell with an AMSI bypass
What is the process for manually breaking signatures in open-source tools?|Compile the software, use ThreatCheck to locate triggering bytes, modify source code accordingly, and repeat until the binary is undetected
What is a TypeLib GUID and why is it important for antivirus detection?|A supposedly unique identifier in .NET assemblies that antivirus solutions commonly use to detect known malicious tools like Rubeus
How does reflectively loading assemblies in PowerShell work?|The .NET assembly bytes are loaded into memory using System.Reflection.Assembly.Load(), and then methods can be called directly without writing files to disk
Why is compressing and encoding assemblies with GZIP and Base64 useful for reflective loading?|It reduces the size of the assembly stored in the PowerShell script and helps avoid signature-based detection of the raw assembly bytes
What is User Account Control (UAC)?|A Windows security feature that manages elevation between access tokens, prompting users when actions require a higher integrity level
What are the four integrity levels in Windows?|Low (internet interactions), Medium (default), High (elevated access), and System (highest possible)
What access tokens does an administrator receive upon login?|A standard user access token with medium integrity level (used by default) and an administrator access token with high integrity level
What does bypassing UAC mean from an attacker's perspective?|Elevating from medium to high integrity level when controlling an administrative user without GUI access
How does the DiskCleanup Scheduled Task UAC bypass work?|The SilentCleanup task runs with highest privileges and uses the %windir% environment variable in its program path, which a user can modify to execute arbitrary programs at high integrity
How does the FodHelper UAC bypass work?|fodhelper.exe has AutoElevate set to true and reads the registry key HKCU\Software\Classes\ms-settings\Shell\Open\Command to determine what to execute, which can be modified by the user
Why does removing ".exe" from the FodHelper bypass command help evade Microsoft Defender Antivirus?|Microsoft Defender Antivirus is triggered when it detects ".exe" in the registry value being set, but Windows can still locate binaries without the .exe extension
What is AppLocker?|A Windows defense-in-depth security feature that allows administrators to restrict which apps and files a user can run based on rules for executable files, installer files, scripts, packaged apps, and DLLs
Why are DLL rules not typically enforced in AppLocker?|Microsoft requires administrators to explicitly enable the DLL rule collection due to reduced system performance issues
What are the three default AppLocker rules for executable files?|Everyone may run executables in Program Files, everyone may run executables in the Windows folder, and administrators may run executables anywhere
Why is the default AppLocker ruleset insecure?|There are writable and executable subdirectories within the Windows folder (like C:\Windows\Tasks and C:\Windows\Temp) that standard users can use to bypass the rules
What is "Living off the Land" (LOTL)?|A technique where attackers abuse legitimate binaries already present in the victim's operating system to carry out attacks, helping evade detection and bypass AppLocker
What is the LOLBAS project?|A searchable list of Microsoft-signed binaries and how they may be abused for attacks such as code execution, file downloads, and AppLocker bypasses
What is InstallUtil and how is it abused?|A Microsoft command-line utility for installing/uninstalling server resources that can be abused by extending the System.Configuration.Install.Installer class and overriding the Uninstall method to execute arbitrary code
What is RunDll32 and how is it abused?|A standard Microsoft binary used to load and execute DLLs, which can be abused by creating a .NET DLL with exported methods using a tool like DllExport
What is the difference between managed and unmanaged code?|Unmanaged code is executed directly by the operating system, while managed code is executed by the .NET Common Language Runtime (CLR)
Why can't .NET programs export DLL methods by default?|Because .NET produces managed code, and DLL method exports are a feature of unmanaged code; a tool like DllExport is needed to bridge this gap
What are the four PowerShell language modes?|FullLanguage (no restrictions), RestrictedLanguage (no script blocks), ConstrainedLanguage (malicious operations restricted), and NoLanguage (scripting completely disabled)
What triggers ConstrainedLanguage mode in PowerShell?|When AppLocker is configured on a system, PowerShell automatically switches to ConstrainedLanguage mode for standard users, except for sessions launched with High Integrity Level
What are two key restrictions of ConstrainedLanguage mode?|Add-Type cannot load arbitrary C# or Win32 APIs, and only types from a short whitelist may be used
What is a PowerShell Runspace and how does it bypass ConstrainedLanguage mode?|A Runspace is the operating environment for PowerShell commands; by creating a custom runspace in a C# program, it defaults to FullLanguage mode, bypassing ConstrainedLanguage restrictions
How can downgrading to PowerShell 2.0 bypass security features?|PowerShell 2.0 was released in 2009 before ConstrainedLanguage mode and AMSI were introduced, so forcing a downgrade bypasses both features
Why is PowerShell 2.0 downgrade becoming less viable as a bypass?|PowerShell 2.0 has been deprecated since 2017 and is becoming less common on modern machines
What is RegAsm in the context of LOLBAS?|A Microsoft binary used for registering/unregistering .NET assemblies that can be abused similarly to InstallUtil for code execution while bypassing AppLocker
What is the significance of YARA rules in malware detection?|YARA rules use combinations of strings, byte patterns, and conditions to identify specific malware families, even when file hashes differ
Why does evading antivirus require understanding concepts rather than memorizing specific techniques?|Antivirus evasion is a cat-and-mouse game where attack vectors are susceptible to detection over time, so understanding the underlying concepts allows adaptation when specific techniques become detected
What is P/Invoke in the context of antivirus evasion?|A technology that allows accessing functions in unmanaged libraries (like Windows API) from managed C# code, commonly used in shellcode loaders
What role does VirtualProtectEx play in PE injection?|It changes the memory protection of allocated space in the target process, typically from Read/Write to Read/Execute, before the shellcode is executed
What is the purpose of the CreateProcess function in PE injection?|It spawns the target process (such as notepad.exe) into which the malicious code will be injected
Why is Microsoft Defender Antivirus's signature database significant for attackers?|While not publicly available, it can be explored indirectly with tools like ExpandDefenderSig.ps1, and understanding what it detects helps attackers craft evasion strategies
What does the WScript.Shell object do in VBScript?|It creates a shell object that can execute programs, and is commonly used in VBScript-based phishing payloads
Why is AMSI relevant to VBScript execution?|Windows Script Host (wscript.exe) makes use of AMSI, meaning VBScript payloads need AMSI bypass considerations
What is the AutoElevate attribute in Windows executables?|An attribute that causes a program to automatically elevate from medium to high integrity level when run, which attackers target for UAC bypasses
What information can Get-MpThreat and Get-MpThreatDetection provide?|Get-MpThreat shows the history of detected threats including threat names and severity, while Get-MpThreatDetection shows detection details including file paths, timestamps, and detection source types
What is the relationship between AppLocker and ConstrainedLanguage mode?|When AppLocker is configured, PowerShell automatically switches to ConstrainedLanguage mode for standard users, creating a dual defense that must both be bypassed
What is dnSpy used for in antivirus evasion research?|It is a decompilation tool for .NET programs, useful for examining how AMSI and other security features are implemented in .NET assemblies
What is the significance of the ScanContent method in AmsiUtils?|It is the method that determines whether input is malicious by calling AmsiScanBuffer; if amsiInitFailed is true, it returns AMSI_RESULT_NOT_DETECTED without scanning
How does AmsiOpenSession validate its context?|It checks if the first four bytes of amsiContext equal "AMSI"; if not, it returns E_INVALIDARG (0x80070057), which can be exploited to force an AMSI bypass
